## 📅 按時間先後順序的工作目標與修正要求

### 🎯 階段一：DSP 訊號處理與即時串流管道 (2026-07-04 ~ 2026-07-06)
*   **核心工作目標**：
    針對現場高頻雜訊與非平穩溫升，實作馬達感測數據降噪、共振分析、長時溫升預測，並搭建可相容 1ms 控制週期的實時非同步串流管道。
*   **具體修正與實作方案**：
    - **Kalman 降噪**：實作 `KalmanFilter2D`，對位置與速度進行實時濾波，降低高頻抖動。
    - **頻域共振分析**：實作 `BodeResponseAnalyzer`，從 swept sine 掃頻信號中提取機械共振頻率。
    - **穩定度判定**：提供經典控制系統的傳遞函數實部/虛部奈奎斯特解算。
    - **繞組溫升預估**：採用 AR(1) 係數自動擬合 ARIMA 模型，實作 30 步前瞻溫度預測。
    - **實時串流防護**：基於 `asyncio.Queue` 實作非阻塞的事件驅動串流診斷，內建例外處理防死鎖。
*   **驗收標準與完成狀態**：
    - [x] 位置訊號降噪 RMSE 降低 **40.5%** (實測 4.8327 → 2.8778)。
    - [x] Swept Sine 測試中精準定位並解析出 **290.00 Hz** 的共振頻率（誤差 = 0）。
    - [x] 溫升預估 30 步趨向平穩不發散。
    - [x] 實時診斷時滯控制在 1ms 級別。

### 🎯 階段二：AutoML 平台、輪廓分群與無網貝氏/遺傳尋優 (2026-07-06)
*   **核心工作目標**：
    開發多模型分類與 RUL 壽命回歸的競賽平台；為應對現場無網部署環境，實作不依賴外網第三方尋優庫的超參數調諧優化器。
*   **具體修正與實作方案**：
    - **Stacking 分類與回歸**：整合多種基礎機器學習模型，實現元學習器 Stacking 分類與回歸預測。
    - **無監督分群**：實作 Birch、OPTICS 與 SpectralClustering 三種無監督演算法，對故障特徵群組進行分析。
    - **自主調諧尋優**：
        - `OptunaBayesianTuner`：以隨機森林作為 Surrogate Model 進行主動尋優，避免引用外部連網 API。
        - `GeneticAlgorithmTuner`：基於染色體物種交叉與變異，實現基因演化尋優。
*   **驗收標準與完成狀態**：
    - [x] Stacking 分類故障健康階段 F1-Score 達到 **95.81%**。
    - [x] RUL 回歸預估 $R^2$ 達到 **0.9889**。
    - [x] 無監督分群輪廓係數達到 **0.9294**。
    - [x] 在無網環境下，Bayesian Tuner 最佳化 F1 達到 **94.92%**，GA 演算法 F1 適應度達到 **95.99%**。

### 🎯 階段四：參數物理映射與 SLMP 二進位閉環通訊 (2026-07-07)
*   **核心工作目標**：
    建立與三菱電機暫存器定址無衝突的物理映射，實作二進位 SLMP Client/Server，並在寫入前執行安全減速狀態機防止垂直軸失控下滑。
*   **具體修正與實作方案**：
    - **二進位幀通訊**：實作支援 MC 3E 協議二進位幀 0x0401 批次讀取與 0x1401 批次寫入的 `SLMPClient`。
    - **控制暫存器定址**：映射摩擦力補償為 PE02 (`friction * 100`)，背隙漂移為 PE07 (`drift * 0.8`)，共振頻率為 PA18，Notch 寬度為 PB12。
    - **安全狀態機防護**：回滾寫入參數前，驅動器自動下達 `1200rpm -> 600rpm -> 0rpm` 減速程序，待確認靜止（進入安全 STO 狀態）後才還原。
*   **驗收標準與完成狀態**：
    - [x] 成功通過 SLMPClient 讀取暫存器，校驗 D1018(PA18)=290Hz, D1012(PB12)=435Hz。
    - [x] 在異常狀態下，一鍵安全減速與備份參數還原 (Rollback) 測試 100% 通過。
