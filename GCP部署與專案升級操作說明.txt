二、 本次 GCP Linux 操作用到的完整指令清單 (Command Cheatsheet)
--------------------------------------------------------------------------------

【類別 1：GCP 控制台與主機連線指令】
--------------------------------------------------
1. 在 GCP Cloud Shell 連進真正的 VM 主機：
   gcloud compute instances list
   gcloud compute ssh <您的VM名稱>

2. 開放 GCP 防火牆 Port 80, 5000, 8000 (需在 Cloud Shell 或 GCP 控制台執行)：
   gcloud compute firewall-rules create allow-phm-ports \
       --allow=tcp:80,tcp:5000,tcp:8000 \
       --target-tags=http-server


【類別 2：檔案尋找、目錄建立與複製指令】
--------------------------------------------------
1. 查看家目錄 FileZilla 上傳進來的檔案/資料夾：
   ls -la /home/mrhuang55/

2. 全機尋找專案核心檔案位置：
   sudo find / -name "server.py" 2>/dev/null

3. 建立標準部署目錄並轉移權限：
   sudo mkdir -p /opt/phm_system
   sudo chown -R mrhuang55:mrhuang55 /opt/phm_system

4. 將 FileZilla 上傳的 Servomotor 資料夾複製到部署目錄：
   cp -r /home/mrhuang55/Servomotor/* /opt/phm_system/
   cd /opt/phm_system
   ls -la


【類別 3：Linux 套件安裝與 Python 虛擬環境建立】
--------------------------------------------------
1. 安裝系統 Python venv 與 Nginx 網頁伺服器：
   sudo apt update && sudo apt install -y python3-pip python3-venv python3-full nginx

2. 在 /opt/phm_system 建立並啟用 venv 虛擬環境：
   python3 -m venv venv
   source venv/bin/activate

3. 在虛擬環境內安裝專案所需依賴套件：
   pip install flask requests fastapi uvicorn pydantic
   (或 pip install -r requirements.txt)


【類別 4：服務檢查與手動測試啟動指令】
--------------------------------------------------
1. 檢查通訊埠 5000/8000 是否已有服務在監聽：
   sudo ss -tlpn | grep -E '5000|8000'

2. 啟用虛擬環境並手動啟動前端 Flask：
   cd /opt/phm_system
   source venv/bin/activate
   python3 frontend/run_flask.py

3. 在背景同時啟動後端與前端：
   python3 server.py &
   python3 frontend/run_flask.py &


【類別 5：Systemd 服務常駐與 Nginx 開機自動啟動設定】
--------------------------------------------------
1. 設定後端服務 (/etc/systemd/system/phm-backend.service)：
   sudo cp /opt/phm_system/phm-backend.service /etc/systemd/system/

2. 啟動並設定開機自啟 Systemd 服務：
   sudo systemctl daemon-reload
   sudo systemctl enable --now phm-backend phm-frontend

3. 套用 Nginx 反向代理並重啟：
   sudo cp /opt/phm_system/nginx_phm.conf /etc/nginx/sites-available/phm
   sudo ln -sf /etc/nginx/sites-available/phm /etc/nginx/sites-enabled/default
   sudo systemctl restart nginx
