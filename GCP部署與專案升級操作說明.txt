二、 本次 GCP Linux 操作用到的完整指令清單 (Command Cheatsheet)
--------------------------------------------------------------------------------

【類別 1：GCP 控制台與主機連線指令】
--------------------------------------------------
1. 在 GCP Cloud Shell 連進真正的 VM 主機：
   gcloud compute instances list
   gcloud compute ssh <您的VM名稱>

2. 開放 GCP 防火牆 Port 80, 5000, 8000 (需在 Cloud Shell 或 GCP 控制台執行)：
   gcloud compute firewall-rules create allow-phm-ports \
       --allow=tcp:80,tcp:5000,tcp:8000 \
       --target-tags=http-server


【類別 2：檔案尋找、目錄建立與複製指令】
--------------------------------------------------
1. 查看家目錄 FileZilla 上傳進來的檔案/資料夾：
   ls -la /home/mrhuang55/

2. 全機尋找專案核心檔案位置：
   sudo find / -name "server.py" 2>/dev/null

3. 建立標準部署目錄並轉移權限：
   sudo mkdir -p /opt/phm_system
   sudo chown -R mrhuang55:mrhuang55 /opt/phm_system

4. 將 FileZilla 上傳的專案資料夾複製到部署目錄：
   cp -r /home/mrhuang55/Servomotor/* /opt/phm_system/
   cd /opt/phm_system
   ls -la


【類別 3：Linux 套件安裝與 Python 虛擬環境建立】
--------------------------------------------------
1. 安裝系統 Python venv 與 Nginx 網頁伺服器：
   sudo apt update && sudo apt install -y python3-pip python3-venv python3-full nginx

2. 在 /opt/phm_system 建立並啟用 venv 虛擬環境：
   cd /opt/phm_system
   python3 -m venv venv
   source venv/bin/activate

3. 在虛擬環境內安裝專案所需依賴套件：
   pip install flask requests httpx fastapi uvicorn pydantic pandas numpy scikit-learn joblib
   # 2026-08-07 更新：analysis_api.py 需要 httpx，先前清單漏裝導致 phm-frontend
   # 開機即 ModuleNotFoundError 陷入無限重啟迴圈；scikit-learn/joblib 供日後
   # 串接 演算法核心.pkl 使用。


【類別 4：服務檢查與手動背景測試啟動指令】
--------------------------------------------------
1. 檢查通訊埠 5000/8000 是否已有服務在監聽：
   sudo ss -tlpn | grep -E '5000|8000'

2. 殺掉舊有 Python 背景進程：
   pkill -f "python3 server.py"
   pkill -f "python3 frontend/run_flask.py"

3. 手動開啟虛擬環境並背景啟動：
   cd /opt/phm_system
   source venv/bin/activate
   nohup python3 server.py > backend.log 2>&1 &
   nohup python3 frontend/run_flask.py > frontend.log 2>&1 &


【類別 5：Systemd 服務常駐（指定 venv Python）與 Nginx 啟動設定】
--------------------------------------------------
1. 寫入後端 Systemd 服務檔 (/etc/systemd/system/phm-backend.service)：
   sudo bash -c 'cat <<EOF > /etc/systemd/system/phm-backend.service
   [Unit]
   Description=MITSUBISHI MR-J5 AI Servo PHM FastAPI Service
   After=network.target

   [Service]
   User=root
   WorkingDirectory=/opt/phm_system
   ExecStart=/opt/phm_system/venv/bin/python3 -m uvicorn server:app --host 0.0.0.0 --port 8000 --workers 2
   Restart=always
   RestartSec=3s
   Nice=-10

   [Install]
   WantedBy=multi-user.target
   EOF'

2. 寫入前端 Systemd 服務檔 (/etc/systemd/system/phm-frontend.service)：
   sudo bash -c 'cat <<EOF > /etc/systemd/system/phm-frontend.service
   [Unit]
   Description=MITSUBISHI MR-J5 AI Servo PHM Flask Frontend Service
   After=network.target

   [Service]
   User=root
   WorkingDirectory=/opt/phm_system
   ExecStart=/opt/phm_system/venv/bin/python3 frontend/run_flask.py
   Restart=always
   RestartSec=3s
   Nice=-5

   [Install]
   WantedBy=multi-user.target
   EOF'

3. 重新載入 Systemd 並啟動服務：
   sudo systemctl daemon-reload
   sudo systemctl enable --now phm-backend phm-frontend
   sudo systemctl restart phm-backend phm-frontend

4. 檢查服務運作狀態：
   sudo systemctl status phm-backend phm-frontend

5. 套用 Nginx 反向代理並重啟：
   sudo cp /opt/phm_system/nginx_phm.conf /etc/nginx/sites-available/phm 2>/dev/null || true
   sudo ln -sf /etc/nginx/sites-available/phm /etc/nginx/sites-enabled/default 2>/dev/null || true
   sudo systemctl restart nginx
