## 內容一覽

### A. Live Monitor v3 — 即時監控 / 呈現用（**做樣本首選**）

| 檔案 | 說明 |
|---|---|
| `outputs/models/monitor_v3_clf.joblib` | 早期預警 + 故障子系統分類器（120 維視窗特徵） |
| `outputs/metrics/monitor_v3_eval.json` | 評估結果與誠實聲明 |
| `data/processed/servo_v3/manifest.json` | 30 情境索引（id / 名稱 / 故障類別 / held_out） |
| `data/processed/servo_v3/scenario_01..30.json` | 30 個回放包，每個 600 幀 @ 40 Hz |
| `src/monitor/schema.py` | 特徵與雷達計算的唯一真相來源 |
| `src/monitor/servo_v3_generator.py` | vendored 產生器（1000 Hz、約 142 tags、seed 42 可重現） |
| `src/monitor/build_servo_v3.py` | 離線建置管線 |

**每幀欄位**（前端直接可畫）：

```
t, stage_int, health, rul, gt_prob, warning, alarm, trip,
temperature, current, vibration, encoder, motion, communication,   ← 六軸雷達 0~1
pred_prob, pred_cat
```

`stage_int`：0 normal / 1 early_degradation / 2 warning / 3 alarm / 4 trip

每個 scenario JSON 的 `meta` 另含 `gt_warning_t`、`gt_alarm_t`、`model_alert_t`、`lead_time_s`、
`alarm_code`、`root_cause`、`maintenance_action`，可直接標在時間軸上。

**指標**：held-out 情境（1/7/13/19/25）early-warning F1 **0.9997**、中位提前量 **5.0 s**。

## 快速使用

**只要資料、不跑模型**（調呈現最快）：直接讀 `data/processed/servo_v3/scenario_26.json`。

**要跑推論**：解壓覆蓋到 repo 根目錄後

```bash
pip install -r requirements-dev.txt
python -m src.models.servo_predict          # 印出一筆結構化診斷
```

**完全不想裝環境**：打線上後端

```bash
curl https://icefeather-aifinalproject.hf.space/monitor/scenarios
curl https://icefeather-aifinalproject.hf.space/monitor/scenario/26
curl https://icefeather-aifinalproject.hf.space/servo/model_info
```

## 使用限制（請務必一併轉達，報告 / 簡報引用時要照實寫）

1. **Live Monitor v3 是 AI 產生器合成的 demo 資料**，非真實遙測。故障類別分類器在全部 30 情境上
   訓練（多數類別為單例），屬 in-distribution 參考，**不得宣稱可泛化**。早期預警才是在 held-out
   情境上評分的。
2. **Servo 主線的 FMCRD 是高擬真「模擬」資料集**，非工廠 / 產線遙測。
3. FMCRD 的健康基線取自**零負載**檔（`train_load0`）、LO/MED/HI 取自 `noisy` 檔，因此
   `anomaly_score` 與門檻是**退化與負載條件的混合效應**，非純退化指標。
4. 情境 18 的**背隙（backlash）路徑未獲驗證** —— 該工況為階梯定位循環、無連續反轉激勵，
   `BL_DeadZone` 結構上恆為 0，已標為不適用。
5. 所有輸出定位為**維護決策輔助**，不對馬達下達控制命令。
