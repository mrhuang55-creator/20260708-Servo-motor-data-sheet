1 專案概述與測試目標

本報告針對 AI Servo V5 PHM 平台（Scenarios 01–30 全場景） 進行完整的平台資料庫生成效能與模型診斷準確率驗證。 測試依據三菱電機 MR-J5 伺服驅動器調機規格書及「AI Servo Data Analysis & Feedback Control Whitepaper v4.2」， 覆蓋從 DSP 訊號處理、AutoML 競賽、深度學習、SLMP 閉環通訊到 NumPy MLP 工業落地硬化等五大技術階段。

資料庫由 phm_pipeline.py 的 StreamingDataGenerator 分 10 個分塊追加寫入， 採用 121 個感測與控制 Tags、30 種故障場景標籤（正常佔 13%，其餘 29 種故障各佔 3%）， 確保高類別平衡性與邊緣端部署的輕量化要求。

6 防誤判邏輯斷言機制驗證

6.1 核心防誤判公式

# ── 通訊致控制喪失優先斷言 (Scenario 23 / 29 防誤報) ──
if row["ethercat_packet_loss_pct"] > 2.0 and row["following_error_abs_pulse"] > 100.0:
    return "communication_loss_of_control"   # 優先攔截，排除機械卡阻誤報

# ── 防抖滑動平均電流過濾器 ──
SMA_current = (1/W) * Σ I[t-W+1 : t]
if SMA_current > threshold:               # 連續視窗平均超標 → 判定真故障
    trigger_rollback()

# ── 安全減速停機狀態機（回滾前執行）──
Speed_cmd = { 1200 rpm (t=0), 600 rpm (t=1), 0 rpm (t=2: 確認靜止 → STO) }
